# VisionPilot — 60-Second Competition Pitch

"Today's AI assistants have a fundamental gap: they generate advice, but leave the execution to you. The few agents that attempt desktop automation rely on brittle pixel clicking, lack safety boundaries, and blindly assume success without checking ground truth.

**VisionPilot** changes that. It is a privacy-first visual computer-use AI agent designed for Snapdragon AI PCs, driven by our core loop: **See. Understand. Act. Verify.**

First, VisionPilot perceives the screen without fragile pixel coordinates by fusing the Windows UI Automation tree with local Windows Media OCR. 

Second, it generates structured execution plans with explicit preconditions and postconditions, evaluated by an authoritative Safety Gate that unconditionally prohibits destructive commands and shell injection.

Third, after executing an authorized action, VisionPilot's independent Verification Engine checks ground truth—such as confirming that a moved file actually exists at the destination and is absent from the source.

Finally, everything is local-first, with zero cloud streaming, push-to-talk privacy, and transparent hardware runtime detection.

VisionPilot transforms desktop AI from answering questions to safely getting work done."
